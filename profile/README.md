# Kauno arkivyskupija

Kauno arkivyskupijos kurijos informacinių sistemų kūrimo ir priežiūros
organizacija.

## Ką darome

Kuriame ir prižiūrime vidines sistemas, padedančias kurijai ir parapijoms
tvarkyti kasdienius duomenis:

- parapijų, dvasininkų ir bendruomenių apskaitą;
- sakramentų metrikų įrašus ir dokumentų generavimą;
- dokumentų, sutarčių ir renginių valdymą;
- kurijos ūkinę ir finansinę apskaitą.

Pagrindinė sistema pasiekiama adresu [mano.kakc.lt](https://mano.kakc.lt).

## Kaip dirbame

- SvelteKit ir TypeScript
- SQLite ir Drizzle ORM
- Docker (arm64) ir GitHub Actions
- Savarankiškai talpinama infrastruktūra

Dauguma saugyklų yra privačios: jose esantys kodas ir duomenys nėra viešai
prieinami.
